# ✅ Todo List App

A clean and responsive Todo List application built using HTML, CSS, and JavaScript.

## 🚀 Features

- Add tasks
- Delete tasks
- Mark tasks complete
- Responsive design
- Dynamic task updates

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```bash
todo-list-javascript/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## ▶️ How to Run

1. Download project
2. Open folder
3. Run `index.html`
